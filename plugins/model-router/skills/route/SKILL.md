Answer in at most ten lines.

1. If a task was given ("$ARGUMENTS"), name its class (quick, search, write, edit, debug, risky, review, research or plan), the pair it starts on, whether a cheap check (tests, a command, a fact to look up) lets it start on the pair in parentheses, and which worker should take the bulk of it: model-router:scout (Haiku 5.5 · low: find, read and list), model-router:runner (Haiku 5.5 · low: runs tests and commands, reports the exact command and its output), model-router:builder (Sonnet 5.5 · high: one scoped edit from a brief, then runs the brief's check), model-router:reviewer (Opus 5.5 · high: risky diffs, and any step that failed twice).
2. Then where each class starts. The first pair is the start, a pair in parentheses is the start when a cheap check exists, and the pairs after "then" are the steps to climb, one each time the check fails. Max plan: quick and search: Haiku 5.5 · low, then Haiku 5.5 · high → Sonnet 5.5 · high; write: Sonnet 5.5 · medium, then Opus 5.5 · medium → Opus 5.5 · high → Opus 5.5 · xhigh; edit: Sonnet 5.5 · high (Sonnet 5.5 · medium with a cheap check), then Opus 5.5 · medium; debug: Fable 5.2 · low (Opus 5.5 · medium with a cheap check), then Fable 5.2 · medium → Opus 5.5 · xhigh → Fable 5.2 · xhigh; risky: Opus 5.5 · high, plan first; review: Opus 5.5 · high, then Fable 5.2 · medium; research: Fable 5.2 · low (Opus 5.5 · medium with a cheap check), then Fable 5.2 · high → Fable 5.2 · xhigh; plan: Fable 5.2 · medium, then Fable 5.2 · high → Fable 5.2 · xhigh. Pro plan: quick and search: Haiku 5.5 · low, then Haiku 5.5 · high → Sonnet 5.5 · high; write: Sonnet 5.5 · medium, then Opus 5.5 · medium → Opus 5.5 · high → Opus 5.5 · xhigh; edit: Sonnet 5.5 · high (Sonnet 5.5 · medium with a cheap check), then Opus 5.5 · medium; debug: Opus 5.5 · high (Opus 5.5 · medium with a cheap check), then Opus 5.5 · xhigh; risky: Opus 5.5 · high, plan first; review: Opus 5.5 · high; research: Opus 5.5 · high (Opus 5.5 · medium with a cheap check), then Opus 5.5 · xhigh; plan: Opus 5.5 · high. When unsure: Sonnet 5.5 · high. Is it a small bug with all its code in the prompt? That is a scoped fix, not debugging: Sonnet 5.5 · high, and run the code to check. Does the prompt name an effort? It wins: use the named effort on the start model of that class. Risky work still never goes below Opus 5.5 · high. Max effort is on no ladder.
3. Remind: an effort change keeps the cache (`/effort <level>`, or `ultrathink` for one turn); a model switch (`/model <name>`) re-reads the conversation, so switch at the start of a task.
